# Read the model script before you ask where a spot stands

**Learned:** 2026-11-26 · **From:** /spec full-umrah

Pause 1 asked where the tahallul marker stands, and said that the mas'a "ends at a wall behind Marwah". That came from the top-view map. `tools/masa.py` has no end wall, and its floor runs on past each hill. The user chose an answer built on the wrong premise, and pause 3 had to ask again and supersede D108.

Wrong: describe a 3D place from its map. Right: read the Blender script of the place before a question about where something stands in it.
