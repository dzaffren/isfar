Marble

The floor around the Kaabah. Use it as the ground of each page, behind the panels. Never put a panel's text on it without a panel.

Cloth

The ihram cloth. Use it for panels, cards, quiet buttons and answer options. Each cloth control has an outline and a lip.

Kiswah

The black cloth of the Kaabah, with one flat gold band. Use it for the panel header, the recitation block and a chosen answer. Nothing else is dark.

Rules

Each texture is a CSS pattern, never a photo. Over the 3D scene, text sits on cloth or kiswah, never on the scene. No blur, no gloss, no gradient fills.
